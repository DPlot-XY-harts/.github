# DPlot

> DPlot keeps a data worksheet, XY charts, and contour views on one figure set so a plot can be read without guessing which series belongs to which column.

---

## Four Beats

1. **Name the job.** Title the DPlot figure set before you paste columns.
2. **Pin the live set.** Keep this series on the worksheet and leave other files aside.
3. **Check once.** Read labels before you add a contour view.
4. **Close the loop.** Leave a note so the next visit does not start from a raw table.
5. **Keep the pair.** The chart and the worksheet stay in the same file.

## First Questions

**Does DPlot replace every other program?**  
No. DPlot sits beside the tables and files you already use.

**Can two people share one computer?**  
Yes. Each person keeps a separate DPlot figure set.

**Will a dense table stay readable?**  
Yes, if only the live series stay on the worksheet.

**What should a new user try first?**  
One short XY chart today, then the same file tomorrow.

**Can a contour sit with an XY chart?**  
Yes. Both can stay in the same DPlot figure set.

## Who Sits Down at DPlot

- **Lab work** — measured columns stay with the chart.
- **Study** — a small series is enough for a first pass.
- **Report prep** — the figure set is easy to show.
- **Shared desk** — each file keeps its own series.
- **Handoff** — the next person reads which chart to open.
- **Archive** — old plots stay out of the live set.

## Field Note

DPlot is easier to trust when the file stays smaller than the folder of old plots. Name the set, keep the live series, and write which chart still matters. That record is short: not every column from the lab, only the path back to this figure.

The same pass fits a lab hour or a short report. Open the last file, finish one chart, and leave fewer loose tables than you found.

## One Real Pass

Pick a table that already has a name. Open it in DPlot, keep only those columns, and finish one visible chart. Extra series wait for their own title.

If the worksheet feels crowded, the set is too wide. Drop anything that belongs to a different job. The next pass can have its own name.
